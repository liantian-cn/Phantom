# 项目说明

## 基本信息

- 项目名称：Phantom
- 作者：`liantian-cn`
- 仓库：`git@github.com:liantian-cn/Phantom.git`
- 开发分支：`develop`
- 目标游戏版本：World of Warcraft 12.1 系列

- 开发环境：WSL2 与 Docker 容器

所有项目修改只在 `develop` 分支完成。用户会手动把特定版本冻结到 `main`，Agent 不得自行修改这一发布流程。

## 项目目标

Phantom 是面向魔兽世界战斗循环的自动化工具。它根据用户配置的条件和优先级，在每个循环周期选择至多一个动作，帮助执行加血或输出逻辑。

核心闭环如下：

1. Python 根据 rotation 和条件插件生成 WoW 插件 Lua。
2. Lua 在游戏画面角落用 Cell、Value Bar 或 Icon Tile 表达条件数据。
3. Python 截取对应屏幕区域并解码为普通 Python 值。
4. Python 按顺序求值 rotation，选择本轮动作或不执行动作。
5. Python 把所选键位发送到魔兽世界窗口，然后进入下一轮。

## 设计原则

### 按需生成像素

生成的 Lua 只包含所选 rotation 实际需要的条件与输出区域，减少长期刷新无关像素带来的游戏端 CPU 开销。

### 插件版本隔离

条件、行为和截图能力按精确版本插件组织。新版本可以与旧版本并存，已测试配置继续引用自己的精确版本，避免修复新逻辑时破坏旧配置。

### 面向 Agent 的配置与文档

- rotation 使用便于人工审阅的 TOML。
- 配置字段和代码标识符使用稳定英文命名；标题与业务注释可以使用中文。
- 插件明确声明参数、输出、来源、风险、兜底和版本变化，使 Agent 能追溯契约。

`python -m rotations.main` 现在提供采集启停、游戏检测、第一行通用数据展示和独立业务日志；rotation 加载、
插件生成、条件与决策展示和动作发送仍未接入。截图模块已进行图像业务测试与 Windows 桌面验证，

新界面不以旧项目 Terminal 为视觉或交互参考。
