# 项目说明

## 基本信息

- 项目名称：Phantom
- 作者：`liantian-cn`
- 仓库：`git@github.com:liantian-cn/Phantom.git`
- 开发分支：`develop`
- 目标游戏版本：World of Warcraft 12.1 系列

## 项目目标

Phantom 是面向魔兽世界战斗循环的自动化工具。它根据用户配置的条件和优先级，在每个循环周期选择至多一个动作，帮助执行加血或输出逻辑。

核心闭环如下：

1. Python 根据 rotation 和条件插件生成 WoW 插件 Lua。
2. Lua 在游戏画面角落用 Cell、Value Bar 或 Icon Tile 表达条件数据。
3. Python 截取对应屏幕区域并解码为普通 Python 值。
4. Python 按顺序求值 rotation，选择本轮动作或不执行动作。
5. Python 把所选键位发送到魔兽世界窗口，然后进入下一轮。

## 设计原则

### 按需生成像素

生成的 Lua 只包含所选 rotation 显式声明的条件与输出区域（包括尚未被规则引用的条件），减少长期刷新无关像素带来的游戏端 CPU 开销。

### 插件版本隔离

条件、键盘和截图能力按精确版本插件组织。新版本可以与旧版本并存，已测试配置继续引用自己的精确版本，避免修复新逻辑时破坏旧配置。

### 面向 Agent 的配置与文档

- rotation 使用便于人工审阅的 TOML。
- 配置字段和代码标识符使用稳定英文命名；标题与业务注释可以使用中文。
- 插件明确声明参数、输出、来源、风险、兜底和版本变化，使 Agent 能追溯契约。

## 当前交付边界

已建立架构、协议、配置和开发规则、Lua 基础、Python 工程基础与 Textual 主界面。
`python -m phantom.main` 提供采集启停、游戏检测、通用数据、独立业务日志、单份 rotation 加载与插件生成、条件值表格。表达式决策及宏名称日志已接入；单次试运行仅保留在独立 demo；宏绑定生成、版本化键盘发送与新帧驱动持续运行已接入，真实游戏闭环仍待验收。血 DK 插件生成与游戏内加载由用户确认通过。界面与配置规则见 [tui.md](tui.md)。

已确认的 UI 技术是 Textual，界面采用终端文本用户界面（TUI），固定使用 Phantom 纯黑深色配色，颜色以 TUI 规范和 phantom/ui/theme.py 为准。
新界面不以旧项目 Terminal 为视觉或交互参考。
